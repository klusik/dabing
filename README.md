# Dabing

Dabing je webové studio pro společné nahrávání audioknih. Autor importuje
strukturovaný scénář, pozve další hlasy a sestaví poslech z nahraných replik.

`main` drží stabilní stav projektu. Vývoj probíhá na pracovních větvích
`feature/*`, které se po ověření integrují squashem do `develop`.
